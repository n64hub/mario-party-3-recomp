The file select's glove slides smoothly between files. Like v0.2.29 it contains no game data: you need your own ROM of the USA release (a big-endian `.z64` of 32 MiB, SHA-1 `6beb80ff822b96bcf85dcdb512e8b2b7969d8259`). Other regions are not supported.

> **Made with AI.** Almost all of the code was written by AI agents (Claude), directed and play-tested by a person.

**Windows:** unzip `MarioParty3Recompiled-v0.2.30-windows-x64.zip` and run `MarioParty3Recompiled.exe` from that folder (it needs a recent Visual C++ 2015-2022 redistributable, x64). **Linux (x86-64):** extract `MarioParty3Recompiled-v0.2.30-linux-x64.tar.gz` and run `MarioParty3Recompiled` in that folder (glibc 2.35 or newer, a Vulkan driver, GTK 3 and FreeType; it brings its own SDL2). Pick your ROM with **Load ROM**, then **Start Game**: the ROM is stored, so the next start goes straight to the game.

**Fixed:**

- On the file select, the white glove that points at a file jumped to the next one in 30 steps a second on the desktop, while the stars behind it moved at the display's rate. It now slides smoothly at the display's rate, as it already did in the browser.

**Not checked yet:** long play sessions, rumble on a physical pad (it was played in the browser with stand-in pads), and the Linux build on a GPU (it has been booted on Mesa's software Vulkan only). Reports are welcome on the [issues page](https://github.com/n64hub/mario-party-3-recomp/issues).
