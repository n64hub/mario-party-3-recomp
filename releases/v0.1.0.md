The first prerelease of Mario Party 3: Recompiled for Windows and Linux: a native PC port of the N64 game made by static recompilation. It is not an emulator and contains no game data: you need your own ROM of the USA release (a big-endian `.z64` of 32 MiB, SHA-1 `6beb80ff822b96bcf85dcdb512e8b2b7969d8259`). Other regions are not supported.

> **Made with AI.** Almost all of the code was written by AI agents (Claude), directed and play-tested by a person.

**A prerelease:** the game plays from its menus through its boards and minigames, but not every minigame and board event has been played through yet, so expect the odd thing drawn wrong. Reports are welcome on the [issues page](https://github.com/n64hub/mario-party-3-recomp/issues).

**Windows:** unzip `MarioParty3Recompiled-v0.1.0-windows-x64.zip` and run `MarioParty3Recompiled.exe` from that folder (it needs a recent Visual C++ 2015-2022 redistributable, x64). **Linux (x86-64):** extract `MarioParty3Recompiled-v0.1.0-linux-x64.tar.gz` and run `MarioParty3Recompiled` in that folder (glibc 2.35 or newer, a Vulkan driver, GTK 3 and FreeType; it brings its own SDL2). Pick your ROM with **Load ROM**, then **Start Game**: the ROM is stored, so the next start goes straight to the game.

**What works:** the menus, its six boards and the minigames, with sound, the game's EEPROM saves kept across restarts, and keyboard and gamepad input. Up to four people play, each with a pad of their own or the keyboard (the menu's Controls, Assign players).

**Enhancements**, each an option on the settings menu's Graphics tab with an Original value that plays as the console does:

- High resolution at the window's size
- Smooth motion at the display's refresh rate, the boards' cameras and pieces blended between the game's frames
- Widescreen: each board's view and background reach the window's edges and the players' panels its corners; scenes the game draws for 4:3 only keep black at the sides
- Keyboard and gamepad controls, rebindable

**Not checked yet:** long play sessions, rumble on a pad, and the Linux build on a GPU (it has been booted on Mesa's software Vulkan only).

The [README](https://github.com/n64hub/mario-party-3-recomp#readme) has what works and how to build it yourself. The same game also plays in a browser, with your ROM, at [n64hub.com](https://n64hub.com/#mario-party-3).
