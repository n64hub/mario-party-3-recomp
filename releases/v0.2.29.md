M.P.I.Q.'s mushroom stalks no longer have thin rings round them. Like v0.2.28 it contains no game data: you need your own ROM of the USA release (a big-endian `.z64` of 32 MiB, SHA-1 `6beb80ff822b96bcf85dcdb512e8b2b7969d8259`). Other regions are not supported.

> **Made with AI.** Almost all of the code was written by AI agents (Claude), directed and play-tested by a person.

**Windows:** unzip `MarioParty3Recompiled-v0.2.29-windows-x64.zip` and run `MarioParty3Recompiled.exe` from that folder (it needs a recent Visual C++ 2015-2022 redistributable, x64). **Linux (x86-64):** extract `MarioParty3Recompiled-v0.2.29-linux-x64.tar.gz` and run `MarioParty3Recompiled` in that folder (glibc 2.35 or newer, a Vulkan driver, GTK 3 and FreeType; it brings its own SDL2). Pick your ROM with **Load ROM**, then **Start Game**: the ROM is stored, so the next start goes straight to the game.

**Fixed** ([#104](https://github.com/n64hub/mario-party-3-recomp/issues/104)):

- In M.P.I.Q., the mushroom stalks had thin teal and green rings round them, between the numbers: what is behind the stalk, seen through hairline gaps between its pieces. Each piece now reaches down over the gap below it, so the stalks are solid white at every resolution, as in the reference picture in the report.
