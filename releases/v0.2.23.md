An update of the renderer and runtime every recomp of this project shares. Like v0.2.22 it contains no game data: you need your own ROM of the USA release (a big-endian `.z64` of 32 MiB, SHA-1 `6beb80ff822b96bcf85dcdb512e8b2b7969d8259`). Other regions are not supported.

> **Made with AI.** Almost all of the code was written by AI agents (Claude), directed and play-tested by a person.

**Windows:** unzip `MarioParty3Recompiled-v0.2.23-windows-x64.zip` and run `MarioParty3Recompiled.exe` from that folder (it needs a recent Visual C++ 2015-2022 redistributable, x64). **Linux (x86-64):** extract `MarioParty3Recompiled-v0.2.23-linux-x64.tar.gz` and run `MarioParty3Recompiled` in that folder (glibc 2.35 or newer, a Vulkan driver, GTK 3 and FreeType; it brings its own SDL2). Pick your ROM with **Load ROM**, then **Start Game**: the ROM is stored, so the next start goes straight to the game.

**Fixed:**

- The frame shown is always the one the game points the screen at.
- Drawing and showing an interpolated frame no longer race each other.
- The picture's bottom row is drawn at every window size.
- A frame is no longer shown while it is still being drawn, which could leave out what the game draws last in it.

These come with N64Recomp-browser v0.205.0's renderer and runtime.

**Not checked yet:** long play sessions, rumble on a physical pad (it was played in the browser with stand-in pads), and the Linux build on a GPU (it has been booted on Mesa's software Vulkan only). Reports are welcome on the [issues page](https://github.com/n64hub/mario-party-3-recomp/issues).

The [README](https://github.com/n64hub/mario-party-3-recomp#readme) has what works and how to build it yourself. The same game also plays in a browser, with your ROM, at [n64hub.com](https://n64hub.com/#mario-party-3).
